# tictactoe — Standard ML Implementation & Optimal Minimax Engine (`tictactoe.sml`)

## Overview
`tictactoe` contains a Standard ML implementation (`tictactoe.sml`) of Tic-Tac-Toe board representation, move generation, win detection, and minimax evaluation, accompanied by Python verification tests (`tests/test_tictactoe.py`).

## Running Verification Tests
```bash
python3 -m unittest discover -s tests -p "test_*.py"
```
